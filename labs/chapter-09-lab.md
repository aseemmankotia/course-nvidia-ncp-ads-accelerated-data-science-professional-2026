# Chapter 9 Lab: Graph Analytics with cuGraph and Geospatial Awareness with cuSpatial

**Estimated time:** 22 minutes

## Exercise

Walkthrough: build a transaction graph, run cugraph.pagerank and cugraph.louvain to surface a fraud ring, then run a cuSpatial point-in-polygon query on associated location data

## Key takeaway

When the question is about relationships between entities, reach for cuGraph; when it's about location, reach for cuSpatial.
